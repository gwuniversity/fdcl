FDCL released an open-source software library for harmonic analysis on SO(3). The **FFTSO3** library supports parallel computation with OpenMP.

Fourier analysis on the rotation group provides computational tools for working with functions and probability densities over three-dimensional orientations. The original announcement links to the software repository.
