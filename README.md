# FDCL Homepage

Generated by [Jekyll](https://jekyllrb.com) using [Nomod theme](https://jekyllthemes.io/theme/nomod-blog-jekyll-theme)

### Setting

*   Install Jekyll according to [Jekyll Installation](https://jekyllrb.com/docs/installation/)
*   Follow the tutorial at [Ruby 101](https://jekyllrb.com/docs/ruby-101/)
*   Development
    *   Run `build.sh`
    *   Run `server.sh`
    *   Open a browser at [http://127.0.0.1:4000](http://127.0.0.1:4000)

*   Deployment
    *   Commit your update and push it to [https://github.com/gwuniversity/fdcl](https://github.com/gwuniversity/fdcl)
    *   The updated homepage will be automatically deployed to [https://fdcl.engineering.gwu.edu/](https://fdcl.engineering.gwu.edu/) in a few minutes

### How to Update

*   To add a lab member
    *   Create a Markdown file under `_members/` using an existing member as a template. Keep the filename stable because it determines the profile URL.
    *   Set `name`, `role` (`professor`, `postdoc`, `graduate`, `undergraduate`, or `alumni`), `role_title`, `image`, a short `research_summary`, and `bio`. Portraits belong in `images/students/`; use the existing placeholder until a portrait is available.
    *   Use `start_year` and `end_year` for lab affiliation rather than a single ambiguous year. `appointment_start_year` identifies the start of a current postdoctoral appointment. Optional `appointments` list the role and dates of each period; `degree` and `thesis_title` record confirmed completed degrees and thesis titles.
    *   Set a unique `username` to connect article authorship to this profile. The article’s `author` must match it exactly (including capitalization), e.g., `ben` or `Taeyoung`. Authored research cards and an expandable news archive appear automatically on the profile, newest first.
    *   Add `research_articles` as comma-separated post slugs for other related work (authored articles are automatically omitted from this separate list), and `website` or `linkedin` for professional links. Current members sort alphabetically within their role; alumni sort by the end of their lab affiliation. Confirm a role change before moving a member to Alumni.

*   To add a news article
    *   Create a Markdown file under `_news/` using an existing article as a template. Set `layout: news`, `title`, `date`, `author` (the writer’s member `username`), `description`, and `image` with descriptive `image_alt` text.
    *   News cards show the article date and sort newest first. The homepage carousel and `/news/` both include the full archive. Carousel images load lazily as they approach the visible area. An optional `card_title` provides a shorter card headline while preserving the full article title.
    *   Historical Facebook news uses the original announcement date, links back to the public post or photo, and keeps recruiting notices explicitly archived. `_data/facebook_news_import.json` maps source posts to articles so later imports can avoid duplicates. Entries marked `ignored` record publication announcements and editorial appointments intentionally omitted from the news archive. Original lab photographs are stored in `images/news/facebook/`; no Facebook login or remote image loading is required to view them.

*   Site search automatically includes research articles, news, member profiles, and titled pages. Member roles, biographies, and research summaries are searchable. Add `search: false` to a page's front matter to omit it from search. Unused theme demo pages and fictional authors are excluded in `_config.yml`; comments are disabled in `_data/settings.yml`.

*   To update publications
    *   Edit the bibliographic records in `../tylee.bib`, then run `python3 bib2pub.py` in `../Vitae/`. This regenerates both the CV publication list and `_pages/publication.md`; do not edit the generated page directly.
    *   Supplemental website links live in `_data/publication_resources.json`, keyed by the exact BibTeX citation key. Supported fields are `preprint`, `code`, `video`, and `overview` (a local research-article path). DOI links come directly from the bibliography. Only add links verified for that publication; the generator rejects unknown citation keys.
    *   The generator keeps chapters under Journal Articles, sorts by descending year/month (unknown months last), and preserves Submitted/Accepted status and award notes. Search filters entries without renumbering them. Run `python3 -m unittest test_bib2pub.py` in `../Vitae/` to check the generator's rendering rules.

*   To add a featured research article
    *   Create a Markdown file under `_posts/` named `YYYY-MM-DD-slug.md`, using an existing research article as a template. Set `title`, `description`, `image`, and `author` (the writer’s member `username`), and use `tags: [Research]` to include it in Featured Research.
    *   Article and news bylines appear on the full article pages and link directly to the writer’s Team profile; cards omit author names and portraits. `author` identifies the writer of the website article; it does not replace the author list of the underlying publication.

*   To add a video in the About FDCL section
    *   Follow [Adding a homepage video](#adding-a-homepage-video) below.

*   To add a demonstration on the Experiments page, add an item under `experiment:` in `_data/settings.yml` with `caption`, a short `summary`, and `group` (`agile`, `transport`, or `perception`). Supply either `youtube_id` or a local `video` path with a `poster` image. An optional `research` path links to the related research article. The page groups these entries automatically and displays two columns on desktop and one on mobile.


### Adding a homepage video

Use a short demonstration of what the system does, rather than a presentation of the paper's novelty. Aim for about **5 seconds**; the existing clips are roughly 4–7 seconds long.

1. Save a compressed MP4 in `videos/`. H.264 video with `yuv420p` pixel format, a width of 960 pixels, and 24 frames per second works well. Audio is unnecessary because the carousel plays muted.
2. Save a representative frame as a JPEG in `images/video-posters/`. This preview appears before playback starts.
3. Append an entry to the existing `about.about_videos` list in `_data/settings.yml`, matching its indentation:

   ```yaml
       - video: /videos/example.mp4
         poster: /images/video-posters/example.jpg
         caption: 'Short description of the demonstration'
   ```

   These are website paths, starting with `/`. Quote captions, especially those containing a colon. List order determines playback order; the navigation dots update automatically.

4. Refresh the local homepage and check the preview, caption, playback, and controls at desktop and mobile widths.

For example, run the following from the website directory with FFmpeg installed. Replace `source.mp4`, the start time (`108` seconds), and the output name (`example`) as needed:

```sh
clip_tmp=$(mktemp -d)
ffmpeg -ss 108 -i source.mp4 -t 5 -an \
  -vf 'scale=960:-2,fps=24' -c:v libx264 -crf 27 \
  -preset medium -pix_fmt yuv420p -movflags +faststart \
  "$clip_tmp/example.mp4"
ffmpeg -ss 1 -i "$clip_tmp/example.mp4" -frames:v 1 -q:v 3 \
  "$clip_tmp/example.jpg"
mkdir -p videos images/video-posters
mv "$clip_tmp/example.mp4" videos/example.mp4
mv "$clip_tmp/example.jpg" images/video-posters/example.jpg
```

Generate the files outside the website directory before moving them into place, so the running Jekyll server does not copy a partially written video. Choose an unused output name for each new clip.

The carousel advances when each clip ends. Play/Pause appears on hover or keyboard focus and remains visible on touch screens. Playback starts paused when the visitor requests reduced motion.
