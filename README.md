# FDCL Homepage

Generated by [Jekyll](https://jekyllrb.com) using [Nomod theme](https://jekyllthemes.io/theme/nomod-blog-jekyll-theme)

### Setting

*   Install Jekyll according to [Jekyll Installation](https://jekyllrb.com/docs/installation/)
*   Follow the tutorial at [Ruby 101](https://jekyllrb.com/docs/ruby-101/)
*   Development
    *   Run `build.sh`
    *   Run `server.sh`
    *   Open brower at [`https://127.0.0.1:4000`](https:/127.0.0.1:4000)

*   Deployment
    *   Commit your update and push it to [https://github.com/gwuniversity/fdcl](https://github.com/gwuniversity/fdcl)
    *   The updated homepage will be automatically deployed to [https://fdcl.engineering.gwu.edu/](https://fdcl.engineering.gwu.edu/) in a few minutes

### How to Update

*   To add lab members
    *   Create a new markdown file at `/_members/` similar to other existing files
    *   Copy a photo image to `images/student/`

*   To add news articles
    *   Create a new markdown file at `/_news/`

*   To update publication

*   To add featured researech
    *   Create a new markdown file under `/_pages/` similar to `open_position.md`
