# FDCL Homepage

Generated by [Jekyll](https://jekyllrb.com) using [Nomod theme](https://jekyllthemes.io/theme/nomod-blog-jekyll-theme)

### Setting

*   Install Jekyll according to [Jekyll Installation](https://jekyllrb.com/docs/installation/)
*   Follow the tutorial at [Ruby 101](https://jekyllrb.com/docs/ruby-101/)
*   Development
    *   Run `build.sh`
    *   Run `server.sh`
    *   Open a browser at [http://127.0.0.1:4000](http://127.0.0.1:4000)

*   Deployment
    *   Commit your update and push it to [https://github.com/gwuniversity/fdcl](https://github.com/gwuniversity/fdcl)
    *   The updated homepage will be automatically deployed to [https://fdcl.engineering.gwu.edu/](https://fdcl.engineering.gwu.edu/) in a few minutes

### Adding a homepage video

Use a short demonstration of what the system does, rather than a presentation of the paper's novelty. Aim for about **5 seconds**; the existing clips are roughly 4–7 seconds long.

1. Save a compressed MP4 in `videos/`. H.264 video with `yuv420p` pixel format, a width of 960 pixels, and 24 frames per second works well. Audio is unnecessary because the carousel plays muted.
2. Save a representative frame as a JPEG in `images/video-posters/`. This preview appears before playback starts.
3. Append an entry to the existing `about.about_videos` list in `_data/settings.yml`, matching its indentation:

   ```yaml
       - video: /videos/example.mp4
         poster: /images/video-posters/example.jpg
         caption: 'Short description of the demonstration'
   ```

   These are website paths, starting with `/`. Quote captions, especially those containing a colon. List order determines playback order; the navigation dots update automatically.

4. Refresh the local homepage and check the preview, caption, playback, and controls at desktop and mobile widths.

For example, run the following from the website directory with FFmpeg installed. Replace `source.mp4`, the start time (`108` seconds), and the output name (`example`) as needed:

```sh
clip_tmp=$(mktemp -d)
ffmpeg -ss 108 -i source.mp4 -t 5 -an \
  -vf 'scale=960:-2,fps=24' -c:v libx264 -crf 27 \
  -preset medium -pix_fmt yuv420p -movflags +faststart \
  "$clip_tmp/example.mp4"
ffmpeg -ss 1 -i "$clip_tmp/example.mp4" -frames:v 1 -q:v 3 \
  "$clip_tmp/example.jpg"
mkdir -p videos images/video-posters
mv "$clip_tmp/example.mp4" videos/example.mp4
mv "$clip_tmp/example.jpg" images/video-posters/example.jpg
```

Generate the files outside the website directory before moving them into place, so the running Jekyll server does not copy a partially written video. Choose an unused output name for each new clip.

The carousel advances when each clip ends. Play/Pause appears on hover or keyboard focus and remains visible on touch screens. Playback starts paused when the visitor requests reduced motion.
